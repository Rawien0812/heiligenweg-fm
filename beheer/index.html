Inloggen

Je wijzigingen worden direct in je GitHub-repo opgeslagen. Daarvoor heb je één keer een sleutel (token) van GitHub nodig. Die blijft alleen in deze browser.

Hoe maak ik een GitHub-sleutel? (eenmalig, 2 minuten)
  1. Open github.com/settings/personal-access-tokens/new (ingelogd op GitHub).
  2. Token name: bijvoorbeeld Heiligenweg beheer. Expiration: kies zelf, bijvoorbeeld 1 jaar.
  3. Repository access: kies Only select repositories en selecteer heiligenweg-fm.
  4. Permissions → Repository permissions → Contents: zet op Read and write.
  5. Klik onderaan op Generate token, kopieer de sleutel (begint met github_pat_) en plak hem hierboven.

Deze sleutel kan alleen deze ene repo aanpassen. Deel hem met niemand.

Klik op een kop om dat onderdeel open of dicht te klappen.

Hits van je kanalen ophalen

Haalt voor elk YouTube-kanaal in LIVE (algemene bronnen én tijdblokken) de meest bekeken nummers op, met views. Bij ‘Populairste eerst’ draait LIVE die vaker en eerder. Gebruikt je YouTube API-sleutel; doe dit af en toe opnieuw voor nieuwe hits.

YouTube API-sleutelNodig om artiesten op te zoeken

Nodig om per artiest de populairste nummers op te zoeken. De sleutel blijft alleen in deze browser en wordt niet op GitHub gezet.

Hoe krijg ik een YouTube API-sleutel? (gratis, eenmalig ±5 minuten)
  1. Ga naar console.cloud.google.com/projectcreate en maak een project, bijv. Heiligenweg FM.
  2. Open YouTube Data API v3 en klik op Inschakelen (Enable).
  3. Ga naar Inloggegevens → Inloggegevens maken → API-sleutel.
  4. Klik op de sleutel → bij API-beperkingen kies YouTube Data API v3. Bij Applicatiebeperkingen kies Websites en voeg https://rawien0812.github.io/* toe. Opslaan.
  5. Kopieer de sleutel (begint met AIza) en plak hem hierboven.

Gratis dagtegoed: genoeg voor ongeveer 100 artiesten ophalen per dag.

LIVE-tijdblokkenSoul, Bhajan, Bollywood, Lokaal… met bronnen en artiesten

Verdeel de dag in blokken, elk met eigen YouTube-bronnen (elke dag hetzelfde). Een blok zonder eigen bronnen draait de algemene bronnen hieronder. ‘tot 00:00’ betekent tot middernacht.

Algemene bronnen voor LIVEDraaien buiten de blokken en in lege blokken

Plak hier YouTube-kanalen (kanaal-ID UC…), afspeellijsten of losse video’s. Deze draaien buiten de tijdblokken en in blokken zonder eigen bronnen. Leeg = de zenders met een vinkje.

Nieuwe nummers (vaker draaien)Een nieuw nummer een tijdje extra vaak op LIVE, in elk blok

Plak de YouTube-link van een nieuw nummer. LIVE draait het dan gegarandeerd vaak en snel na het openen van de site, en zet er NIEUW bij. Na de gekozen periode stopt het vanzelf. Meerdere nieuwe nummers wisselen elkaar af.

    BezoekerstellerHoeveel mensen nu luisteren en hoe vaak de site is bezocht

    De teller gebruikt een gratis Firebase-database van Google. Er worden alleen anonieme tellingen opgeslagen, geen persoonlijke gegevens.

    Stappenplan (eenmalig, ±5 minuten)
    1. Ga naar console.firebase.google.com en klik op Project maken (of kies je bestaande Google Cloud-project). Google Analytics mag uit.
    2. Kies links Build → Realtime Database → Create Database. Locatie: europe-west1 (België). Kies Start in locked mode.
    3. Open het tabblad Rules, vervang alles door de regels hieronder (knop Regels kopiëren) en klik op Publish.
    4. Klik links op het tandwiel → Project settings → onder Your apps op het icoon </> (Web). Geef een naam, bijv. Heiligenweg FM, en klik op Register app.
    5. Kopieer het blok const firebaseConfig = { … } en plak het hieronder. Klik op Opslaan en publiceren.

    Werkt bij het ophalen (artiesten, hits van kanalen, trending) én tijdens het afspelen op de site: een nummer uit een kanaal of afspeellijst dat niet door de keuring komt, wordt meteen overgeslagen. Losse video’s die je zelf plakt, laat de beheerpagina altijd staan.

    Zoekt op YouTube de meest bekeken nieuwe video’s voor een zoekterm in de gekozen periode en zet de top 5 hieronder (vervangt de huidige lijst). Daarna kun je nog schuiven of weghalen. Gebruikt je YouTube API-sleutel.

    ZendersAlle zenders met hun muziek en tijden

    Plak een YouTube-link bij een zender om muziek toe te voegen. Dat kan een video, een afspeellijst (list=) of een kanaal (/channel/UC… of alleen de kanaal-ID UC…) zijn. Een afspeellijst of kanaal speelt op de site alle nummers af.
