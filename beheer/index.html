Inloggen

Je wijzigingen worden direct in je GitHub-repo opgeslagen. Daarvoor heb je één keer een sleutel (token) van GitHub nodig. Die blijft alleen in deze browser.

Hoe maak ik een GitHub-sleutel? (eenmalig, 2 minuten)
  1. Open github.com/settings/personal-access-tokens/new (ingelogd op GitHub).
  2. Token name: bijvoorbeeld Heiligenweg beheer. Expiration: kies zelf, bijvoorbeeld 1 jaar.
  3. Repository access: kies Only select repositories en selecteer heiligenweg-fm.
  4. Permissions → Repository permissions → Contents: zet op Read and write.
  5. Klik onderaan op Generate token, kopieer de sleutel (begint met github_pat_) en plak hem hierboven.

Deze sleutel kan alleen deze ene repo aanpassen. Deel hem met niemand.

Teksten en instellingen

Een ★ in de busroute wordt op de site een gele ster.

LIVE en overgangen

LIVE is de hoofdzender: hij draait de muziek van de zenders met een vinkje bij Draait mee op LIVE die op dat moment op het programma staan, door elkaar en eindeloos. Vul bij nummers de BPM in (opzoeken kan op songbpm.com) om op tempo te mixen.

Tijdblokken op LIVE

Verdeel de dag in blokken, elk met eigen YouTube-bronnen (elke dag hetzelfde). Een blok zonder eigen bronnen draait de algemene bronnen hieronder. ‘tot 00:00’ betekent tot middernacht.

Algemene bronnen voor LIVE

Plak hier YouTube-kanalen (kanaal-ID UC…), afspeellijsten of losse video’s. Deze draaien buiten de tijdblokken en in blokken zonder eigen bronnen. Leeg = de zenders met een vinkje.

Zenders

Plak een YouTube-link bij een zender om muziek toe te voegen. Dat kan een video, een afspeellijst (list=) of een kanaal (/channel/UC… of alleen de kanaal-ID UC…) zijn. Een afspeellijst of kanaal speelt op de site alle nummers af.

Uitloggen

Gebruik je een computer die niet van jou is? Log dan uit als je klaar bent; de sleutel wordt dan uit deze browser verwijderd.
